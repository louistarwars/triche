# Colorimètre Triche

Page web unique (`index.html`) : le téléphone filme la tablette, mesure la couleur à mémoriser
(teinte / saturation / luminosité), puis compare en direct avec la couleur recréée et indique
dans quel sens et de combien bouger chaque curseur.

La caméra exige HTTPS : héberge le fichier (ex. GitHub Pages) puis ouvre l'URL sur le téléphone.
